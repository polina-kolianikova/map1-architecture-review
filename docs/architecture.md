# Architecture

The source retains React/Mapbox presentation, FastAPI routes, PostgreSQL/PostGIS storage, provider adapters, queue orchestration, audit history, backups and deployment infrastructure.

Ordinary service implementations, command structure, schema revisions and workflow stages are retained. Proprietary assessment functions and producers use explicit unavailable boundaries. Stored-data API readers remain implemented; private rules/configuration endpoints return 501. No production data, map key or calculated fixture dataset is bundled.

The source-to-export mapping is in `scope-projection.json`. Executed architecture checks and integration limits are in `review-results.json`. The complete original CI suite and live PostGIS migration/data qualification are not claimed.
